Лабораторія useState

Змінюй значення та спостерігай, як стан впливає на інтерфейс.

ЛІЧИЛЬНИК
0
const [count, setCount] = useState(0);

function increment() {
  setCount(current => current + 1);
}

return (
  <button onClick={increment}>
    {count}
  </button>
);

Порада: функціональне оновлення setCount(current => current + 1) надійне, коли новий стан залежить від попереднього.
